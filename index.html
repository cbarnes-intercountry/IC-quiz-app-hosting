Image Search

Unsplash supplies the pictures offered by “Find a free image” in the question editor. Free account, no card. Create an app at unsplash.com/oauth/applications and paste its Access Key here.

The key is kept in the database where only signed-in teachers can read it, never in the page itself. Leave it empty and the picker falls back to the Creative Commons archives, which are weaker for everyday subjects.
